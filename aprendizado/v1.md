Beleza, **agora ficou CLARÍSSIMO o que está acontecendo**.

Você rodou:

```
0c29cb2 Add guide for using Git in code reviews with A
```

Ou seja:

### ✅ **Existe exatamente UM commit à frente da main: `0c29cb2`**

Agora você quer:

> **Ver o diff completo desse commit — o que tinha antes e o que tem agora.**

Sim, o Git tem comando pra isso!

---

# ✅ **1. Ver o diff completo de um commit específico**

```bash
git show 0c29cb2
```

Isso vai abrir no pager (`less`), mostrando:

* Arquivos modificados
* Linhas removidas
* Linhas adicionadas

Exemplo de saída:

```diff
diff --git a/README.md b/README.md
index 123abc..789xyz 100644
--- a/README.md
+++ b/README.md
@@ -1,4 +1,10 @@
-Texto antigo aqui
+Texto novo aqui
+Mais linhas adicionadas
```

Se quiser SEM pager (pra não aparecer `~~~~`):

```bash
git --no-pager show 0c29cb2
```

Ou:

```bash
git show 0c29cb2 | cat
```

---

# ✅ **2. Ver só os arquivos alterados nesse commit**

```bash
git diff-tree --no-commit-id --name-only -r 0c29cb2
```

---

# ✅ **3. Ver o diff da sua branch inteira em relação à main**

Se você quiser ver *tudo que mudou desde que você saiu da main*:

```bash
git --no-pager diff origin/main...HEAD
```

Isso mostra:

* O que foi removido
* O que foi adicionado
* Arquivo por arquivo
* Bloco por bloco

Se você quer que abra sem pager:

```bash
git diff origin/main...HEAD | cat
```

---

# ⚠️ IMPORTANTE

Você rodou:

```
git diff --diff-filter=AM --name-only origin/main...HEAD
```

e retornou **nada**.

Isso significa:

### ❗ O seu commit provavelmente **só adicionou arquivos** no stage mas não alterou nada em arquivos que já existiam

OU

### ❗ Os arquivos adicionados foram commitados mas não estão sendo filtrados corretamente porque não possuem extensão `.rb`.

Vamos conferir:

---

# ✅ **4. Ver TODOS os arquivos tocados pelo commit**

```bash
git show --name-only 0c29cb2
```

Isso mostra:

* Conteúdo do commit
* Lista de arquivos mexidos (no final)

Exemplo:

```
commit 0c29cb2
Author: Vitor
Date: ...

    Add guide for using Git in code reviews

README.md
docs/git-guide.md
```

---

# 👉 **Então, o comando que você quer de verdade é:**

## ▶️ Ver o diff completo da PR (uma única tela)

```bash
git diff origin/main...HEAD
```

## ▶️ Ver o diff de UM commit específico

```bash
git show 0c29cb2
```

---

# 💡 Observação final

Se você quer **simular exatamente o que será mostrado numa PR do GitHub**, o comando correto é:

```bash
git diff origin/main...HEAD
```

É *exatamente* isso que o GitHub faz internamente.
